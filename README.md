# AttendTrack

AttendTrack is a Progressive Web App (PWA) designed to help churches track attendance across multiple services.

It allows ushers to count:
- Male attendees
- Female attendees
- Children

The app supports multiple services, saves attendance history, works offline, and can be installed like a mobile application.

---

## 🚀 Live Demo

https://kama-ds10.github.io/attendtrack/

---

## ✨ Features

- Multi-service attendance tracking (4 services)
- Gender-based counting (Male, Female, Children)
- Local storage data persistence
- CSV export for reporting
- Installable as a mobile app (PWA)
- Offline functionality via Service Worker
- Clean, responsive UI
